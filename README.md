# منصة تكوين وآداب نادي جسور

المشروع المكتمل لـ **منصة تكوين وآداب نادي جسور**، والمربوط مباشرة بقاعدة البيانات السحابية لـ Firebase (`josour-moidat`).

## 📁 محتويات المجلد:
- `index.html`: الملف البرمجي التفاعلي الرئيسي بتصميم الأصفر والفضي وشعار النادي ومربوط بـ Firebase.
- `logo.png`: الشعار الرسمي لنادي جسور.
- `README.md`: دليل توضيحي ومختصر للمستودع.
